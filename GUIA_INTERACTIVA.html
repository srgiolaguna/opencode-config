🔮 oh-my-opencode

¿Qué es?

Plugin de orquestación para OpenCode que añade enrutamiento automático de modelos, fallback automático y cadenas de respaldo por agente.

Instalación (ya completada)

brew install bun
bun add -g oh-my-opencode
bunx oh-my-opencode install --no-tui \
  --platform opencode \
  --claude no --openai no --gemini no \
  --copilot no --opencode-zen no \
  --zai-coding-plan no --kimi-for-coding no \
  --opencode-go no

Cómo funciona

  • 1. Enrutamiento automático — decide qué modelo usar según el tipo de tarea
  • 2. Fallback automático — si un modelo falla, prueba el siguiente sin reiniciar
  • 3. Cadenas por agente — cada agente tiene su propia lista de fallback
  • 4. Cadena global — respaldo para todos los agentes

✅ Ventajas

  • 10 agentes especializados
  • 8 categorías de tareas
  • Fallback automático
  • Modelos 100% gratuitos

⚠️ Nota

Doctor muestra 1 warning de compatibilidad (modelos FREE fuera del catálogo). Funcionalidad completa.

🔄 Cadena de Fallback Automático

Si un modelo falla (rate limit, error 500, timeout), el sistema automáticamente prueba el siguiente de la cadena sin perder contexto.

Cadena Global:
nemotron-3-ultra-free → gemini-3.6-flash → nemotron-3.5-lightning-free → mimo-v2.5-free → ling-3.0-flash-fin-free → gpt-5-nano

🎯 Cuándo se activa

  • Rate limit (429)
  • Error del servidor (500, 502, 503, 504)
  • Modelo no encontrado
  • Timeout / sin tokens

🔍 AST-Grep

¿Qué es?

Herramienta de búsqueda y reemplazo de código basada en patrones AST (Abstract Syntax Tree). Permite buscar código por estructura, no solo por texto.

Uso en oh-my-opencode

Habilita el skill ast-grep que permite buscar funciones por patrón AST.

sg — Buscar por estructura AST

Instalación

brew install ast-grep

Versión: ast-grep 0.45.3
