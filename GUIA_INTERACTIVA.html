oh-my-openagent v4.19.4

¿Qué es?

Plugin de orquestación para OpenCode. ✓ Enrutamiento automático de modelos, fallback automático, cadenas de respaldo por agente.

Instalación

brew install bun bun add -g oh-my-openagent bunx oh-my-openagent install --no-tui --platform opencode --claude no --openai no --gemini no --copilot no --opencode-zen no --zai-coding-plan no --kimi-for-coding no --opencode-go no

Funciones

✓ Enrutamiento automático de modelos según tarea

✓ Fallback automático sin perder contexto

✓ 10 agentes especializados + 8 categorías

Ultrawork (ulw) — modo autónomo. Si escribes ulw en el prompt, el agente trabaja sin confirmar cada paso. ✓ GRATIS.

Modo Plan — --plan o /plan. Primero planifica, luego ejecuta. Evita que el agente programe sin entender el problema.

⚠ Bug conocido del doctor

omo doctor marca 10 avisos "Deprecated: fallback_models → models" en la sección agents.*. Es un falso positivo: comprobado en el código fuente del plugin, el schema real de agents.<nombre> solo acepta fallback_models — el campo models solo existe para categories.*. Si lo "arreglas" siguiendo el aviso, omo deja de arrancar ("Unknown config key"). Déjalo tal cual.

Model routing (config real, verificado 17-sep)

Todos los agentes usan Cloudflare Workers AI (gemma) como modelo principal — es el único que se probó en vivo con el toolset completo de omo sin romperse. OpenRouter queda como fallback por agente (ver pestaña AGENTES), sujeto a la cuota compartida de 50/día.

Archivos

~/.omo/omo.jsonc — Configuración principal

~/.bun/bin/omo — Comando omo

Cadena de Fallback

Si un modelo falla (rate limit, error), el sistema prueba el siguiente sin perder contexto. Ojo: todos los fallbacks de OpenRouter comparten la misma cuota diaria de 50 peticiones — si el primario (Cloudflare) también estuviera caído, es poco probable que el fallback de OpenRouter tenga cupo.

Cadena por defecto

cloudflare-workers-ai/@cf/google/gemma-4-26b-a4b-it (principal, verificado) → openrouter/nex-agi/nex-n2.5-mini:free (último recurso, sujeto a cuota)

Launcher — di qué quieres hacer, te doy el comando listo para pegar en Terminal

Un navegador no puede abrir Terminal.app ni ejecutar comandos por ti (por seguridad) — este launcher genera el comando correcto y lo copia al portapapeles. Pégalo con Cmd+V y pulsa Enter.

ULTRAWORK = autónomo sin confirmar. PLAN = primero planifica, luego ejecuta. (No aplican si el comando usa --agent).

⚠ Comprobado el 17-sep: el comando cerrar descrito aquí en versiones anteriores de esta guía no existe — no está en ~/.zshrc, ~/.zshenv ni ~/.alias_gio. cd ~/.config/opencode && git add -A && git commit -m "..." && git push
