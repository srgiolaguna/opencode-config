🔮 oh-my-opencode v4.19.4

¿Qué es?

Plugin de orquestación para OpenCode. Enrutamiento automático de modelos, fallback automático, cadenas de respaldo por agente.

Instalación

brew install bun bun add -g oh-my-opencode bunx oh-my-opencode install --no-tui --platform opencode --claude no --openai no --gemini no --copilot no --opencode-zen no --zai-coding-plan no --kimi-for-coding no --opencode-go no

Funciones

✅ Enrutamiento automático según tipo de tarea

✅ Fallback automático sin perder contexto

✅ 10 agentes especializados + 8 categorías

✅ Cadena global: nemotron-3-ultra-free → gemini-3.6-flash → nemotron-3.5-lightning-free → mimo-v2.5-free → ling-3.0-flash-fin-free

Archivos clave

~/.omo/omo.jsonc — Configuración principal
~/.config/opencode/node_modules/oh-my-openagent/ — Plugin
~/.bun/bin/omo — Comando omo

🔄 Cadena de Fallback

Si un modelo falla (rate limit, error 500, timeout), el sistema prueba el siguiente sin perder contexto.

Cadena Global

nemotron-3-ultra-free → gemini-3.6-flash → nemotron-3.5-lightning-free → mimo-v2.5-free → ling-3.0-flash-fin-free
