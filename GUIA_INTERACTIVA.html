oh-my-opencode v4.19.4

¿Qué es?

Plugin de orquestación para OpenCode. ✓ Enrutamiento automático de modelos, fallback automático, cadenas de respaldo por agente.

Instalación

brew install bun bun add -g oh-my-opencode bunx oh-my-opencode install --no-tui --platform opencode --claude no --openai no --gemini no --copilot no --opencode-zen no --zai-coding-plan no --kimi-for-coding no --opencode-go no

Funciones

✓ Enrutamiento automático de modelos según tarea

✓ Fallback automático sin perder contexto

✓ 10 agentes especializados + 8 categorías

Ultrawork (ulw) — modo autónomo. Si escribes ulw en el prompt, el agente trabaja sin confirmar cada paso. ✓ GRATIS.

Modo Plan — --plan o /plan. Primero planifica, luego ejecuta. Evita que el agente programe sin entender el problema.

MCP Servers (Model Context Protocol)

Conexiones que dan a opencode acceso a fuentes externas:

websearch (Exa) — busca en internet
context7 — lee documentación de librerías
grep_app (GitHub) — busca código en GitHub
LSP — autocompletado, ir a definición, errores de tipos
Hooks: 25+ configurables — reacciones a eventos

✓ Todos gratuitos — ✓ ya integrados en oh-my-opencode

Model routing inteligente

Usa modelos diferentes para cada tipo de tarea para ahorrar tokens:

✓ Tareas rápidas → nemotron-3.5-lightning-free o ling-3.0-flash-fin-free
Coding → deepseek-v4-pro, Qwen2.5-Coder-32B, gpt-oss-120b
Razonamiento → gemini-3.6-flash
Tareas pesadas → nemotron-3-ultra-free o llama-3.3-70b

✓ Gratis — solo organizar cuál modelo usar para qué

Archivos

~/.omo/omo.jsonc — Configuración principal

~/.config/opencode/node_modules/oh-my-openagent/ — Plugin

~/.bun/bin/omo — Comando omo

AST-Grep

brew install ast-grep — Busca código por estructura AST

Cadena de Fallback

Si un modelo falla (rate limit, error 500), el sistema prueba el siguiente sin perder contexto.

Cadena Global

nemotron-3-ultra-free → gemini-3.6-flash → nemotron-3.5-lightning-free → mimo-v2.5-free → ling-3.0-flash-fin-free
