🔮 oh-my-opencode

¿Qué es?

Plugin de orquestación para OpenCode que añade enrutamiento automático de modelos, fallback automático y cadenas de respaldo por agente.

Instalación (ya completada)

brew install bun
bun add -g oh-my-opencode
bunx oh-my-opencode install --no-tui \
  --platform opencode \
  --claude no --openai no --gemini no \
  --copilot no --opencode-zen no \
  --zai-coding-plan no --kimi-for-coding no \
  --opencode-go no

Cómo funciona

  • 1. Enrutamiento automático — decide qué modelo usar según el tipo de tarea
  • 2. Fallback automático — si un modelo falla, prueba el siguiente sin reiniciar
  • 3. Cadenas por agente — cada agente tiene su propia lista de fallback
  • 4. Cadena global — respaldo para todos los agentes

Archivos clave

ArchivoPropósito
~/.omo/omo.jsoncConfiguración principal (agentes, categorías, fallback)
~/.config/opencode/node_modules/oh-my-openagent/Plugin instalado
~/.bun/bin/omoCommando omo (wrapper via bun)

🔄 Cadena de Fallback Automático

Si un modelo falla (rate limit, error 500, timeout), el sistema automáticamente prueba el siguiente de la cadena sin perder contexto.

Cadena Global:
nemotron-3-ultra-free → gemini-3.6-flash → nemotron-3.5-lightning-free → mimo-v2.5-free → gpt-5-nano

🎯 Cuándo se activa

  • Rate limit (429)
  • Error del servidor (500, 502, 503, 504)
  • Modelo no encontrado
  • Timeout / sin tokens
